Documentation

La page compare Baguette seul à Baguette aidé par un petit modèle brouillon. Les réglages actifs sont les mêmes pour les deux méthodes.

Réglages

Prompt
Début du texte donné au modèle avant la génération.
Mode
Échantillonnage : les tokens sont tirés selon leurs probabilités, donc les deux textes peuvent différer. Greedy : le token le plus probable est choisi à chaque étape ; la sortie spéculative doit être identique à celle de Baguette seul. Température, Top-k et Top-p sont ignorés en mode greedy.
Nouveaux tokens
Nombre maximal de tokens à générer. La génération peut s'arrêter plus tôt si le modèle produit un token de fin.
Taille du bloc
Nombre maximal de tokens proposés par le brouillon avant une vérification par Baguette.
Graine
Fixe les tirages aléatoires pour reproduire un essai. Elle n'a pas d'effet sur le texte en mode greedy.
Température
En échantillonnage, une valeur sous 1 favorise les tokens les plus probables ; une valeur au-dessus de 1 augmente la variété.
Top-k
Limite le tirage aux k tokens les plus probables. La valeur 0 désactive ce filtre.
Top-p
Conserve les tokens les plus probables jusqu'à atteindre une probabilité cumulée p. La valeur 1 désactive ce filtre.
Cache d'attention
Réutilise les calculs des tokens précédents. Disponible pour les modèles Baguette sans couches DeltaNet.
Comparer
Lance les deux générations avec le même prompt et les mêmes réglages, puis affiche leurs mesures.

Lire les résultats

Vitesse relative
Rapport entre les débits avec et sans brouillon. Au-dessus de 1×, le décodage spéculatif est plus rapide.
Débit
Nombre de tokens générés par seconde, après chargement des modèles.
Premier token
Temps écoulé avant l'arrivée du premier token.
Durée totale
Temps de génération du texte affiché, sans le chargement des modèles.
Tokens générés
Nombre de tokens réellement produits ; il peut être inférieur à la limite demandée si la génération s'arrête plus tôt.
Propositions acceptées
Part des tokens proposés par le brouillon que Baguette a conservés.
Passages cible / brouillon
Nombre d'appels à chaque modèle pendant la génération mesurée.
